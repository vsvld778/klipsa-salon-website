# Клипса — сайт студии красоты

Публичная версия нового сайта для согласования.

Сайт: https://vsvld778.github.io/klipsa-salon-website/

17 статических страниц, каталог услуг, поиск по прайсу и галерея. HTML, CSS и JavaScript без внешних библиотек. GitHub Pages: ветка `main`, корневая папка.
